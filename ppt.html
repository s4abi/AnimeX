Animex

Anime Streaming Platform
Final Year Computer Science Project
Sahib Thakur Rayat Bahra University

Abstract

AnimeX is a next-generation web-based streaming platform designed to deliver high-quality anime content to users globally.

Built with the modern MERN stack (MongoDB, Express, React, Node.js), it addresses the need for a streamlined, ad-free, and fast viewing experience.

Problem Statement

The Issues

  • Existing platforms are often cluttered with intrusive ads.
  • Premium content is behind expensive paywalls.
  • Slow loading speeds and poor video optimization.
  • Outdated user interfaces that hinder navigation.

The Need

  • A centralized, fast, and clean streaming solution.
  • Optimized for low-latency video playback.
  • Community-driven features like favorites and watch history.
  • Aesthetic design matching the anime culture.

Objectives

  • Develop a smooth streaming engine capable of HD playback.
  • Implement fast search and genre-based filtering.
  • Create a secure User Authentication system (JWT).
  • Enable users to maintain a list of Favorites.
  • Track Watch History for seamless resumption.
  • Ensure fully responsive UI across mobile, tablet, and desktop.

Why MERN?

  • Scalability: Easy to scale both vertically and horizontally.
  • Performance: Non-blocking I/O of Node.js ensures fast streaming.
  • Single Language: JavaScript used throughout (Fullstack).
  • Community: Massive library support and active maintenance.

Future Scope

  • Mobile Application: Development of native Android and iOS apps using React Native.
  • AI Recommendations: Implementing ML algorithms to suggest anime based on viewing history.

  • Community Features: Adding forums, comment sections, and rating systems.

Conclusion

AnimeX successfully delivers a modern anime streaming experience using the MERN stack. It combines optimized performance, a user-friendly design, and robust architecture to solve the issues faced by current platforms.
